What this illustration assumes

This is a deterministic seeded toy simulation, not an LLM training result. Each step samples 40 class groups and applies an assumed diminishing-return learning curve. Classes have different learning rates. There is no transfer, gradient interference, verifier noise, or token cost.

Every step supplies exact reference success probabilities at no cost. Priorities use positive mean progress over the last five steps, divided by a fixed temperature of 0.002, followed by softmax and the exploration reserve. Exact observations stand in for a zero-width progress interval. Real training requires sampled estimates, uncertainty handling, and paid reference observations as described in the proposal.

The horizon of 180 steps only bounds playback; the update rule never reads it. The regression scenario deliberately shows a limitation: negative progress does not receive a positive bonus. Rehearsal starts through coverage, and renewed improvement can then attract practice. At 100% reserve the same learner uses fixed equal class sampling.
