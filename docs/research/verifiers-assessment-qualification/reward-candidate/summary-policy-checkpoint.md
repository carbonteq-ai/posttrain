## What now works

The shared `summary_exclusions@1` manifest check binds an exact public policy,
assistant and external output inventories, and verified action relations.
The generic reducer publishes compliance, violation or unavailable meaning.
A known violation survives unrelated capture gaps. Positive compliance requires
closed assistant, external and invocation inventories, with every observed
output assessed. Exact empty text is deterministically inapplicable; unknown
nonempty prose, including whitespace, remains unavailable without assessment.
An optional summary is never turned into a required action.

`manifest_summary_assessments.py` integrates this check with native assessment
planning, source admission, retention, reload and rescoring. Composition owns
the optional `SummaryBackend` registry and all message preparation and response
parsing. Its identity includes parser/rubric revisions and a nonempty canonical
execution selection. Manifests cannot instantiate clients or cause implicit
inference. The trusted adapter journals its actual request before awaiting
execution and declares which complete outputs were covered independently of
model output. The original response is retained before custom parsing. Invalid
parsing cannot become compliance; a valid violation yielded before a later
iterator failure remains a violation. Cancellation propagates.

This increment adds a guard outcome only. The official episode reward remains
unchanged. Authored-output credit recipients and exact token alignment are
separate work; the check cannot be attached to an unsupported credit policy.
